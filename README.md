# 🍽️ MealMate

**MealMate** is a native Android app developed in **Java using Android Studio**. 
It helps users plan meals, manage groceries, and organize recipes in a simple, intuitive way. Designed with both practicality and user experience in mind, MealMate simplifies shopping, and brings structure to your kitchen routine.

## 🎯 Project Overview

MealMate was created as a prototype app with the following goals:
- Enable users to plan weekly meals effortlessly
- Convert meal plans into automatic grocery lists
- Allow for easy item editing, deletion, and purchase marking
- Support task delegation through **SMS**
- Offer optional enhancements such as store geotagging and app integration


## 🔑 Core Features

### 🏠 Home Screen
- Easy navigation to recipes and grocery lists

### 🔐 Login & Registration
- Secure login with **Firebase Authentication**
- Persistent login using SharedPreferences or Firebase session

### 🧾 Item Management
- Add/edit/delete grocery items
- Mark items as purchased

### 🧑‍🍳 Recipe Creation
- Build custom recipes with ingredients and preparation steps
- Save and reuse recipes across multiple weeks

### 📤 SMS Delegation
- Select items and send them to contacts via SMS
- Useful for shared grocery responsibilities

- ✋ **Gesture Controls**  
  Swipe to delete recipe
